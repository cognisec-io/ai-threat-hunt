CogniSec.io started this board and keeps the lights on, but the case files belong to whoever's hunting. Every vulnerability here is drawn from the open OWASP GenAI, Agentic Security Initiative, and NHI projects — this is a teaching layer on top of community research, not a product.

Found a bug in a fix? Think something's filed wrong? Want to add a threat class we haven't covered? Fork it, file it, send a PR. No account, no gate.
